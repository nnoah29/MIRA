# Traduction de l'interface

Le **français est la langue source** : chaque texte de l'app est écrit en français et sert de clé de
traduction. `t('Texte')` rend le texte dans la langue active, `tn(n, 'message', 'messages')` gère le
singulier / pluriel, `{0}`, `{1}`… sont remplacés par les arguments.

## Règles pour le code

- Tout texte visible passe par `t()` (ou `tn()`). Jamais de texte français en dur dans un widget.
- Un texte stocké dans une donnée ou une constante, affiché plus tard par `t(valeur)`, se déclare avec
  `tkey('Texte')` pour que l'audit le compte.
- Un texte français qui ne doit pas être traduit (motif de recherche, donnée de démonstration…) porte
  `// i18n:ignore` sur sa ligne.
- Les messages d'erreur du moteur sont traduits par code d'erreur (`lib/i18n/engine_errors.dart`), jamais
  affichés tels quels.

## Ajouter une langue (exemple : l'allemand)

1. `python3 tools/i18n-audit --init de` crée `app/lib/i18n/lang/de.dart` avec tous les textes, valeurs vides.
2. Ajouter une ligne à l'enum `AppLang` (`lib/i18n/i18n.dart`) :
   `de('de', 'de_DE', 'Deutsch', deStrings, 'en'),` — le dernier argument est la langue de repli : un texte
   resté vide s'affiche dans cette langue, puis en français. `null` : repli direct sur le français.
3. Traduire les valeurs dans `de.dart`. Un texte vide n'est pas traduit (repli), jamais une erreur.
4. `python3 tools/i18n-audit --lang de` liste ce qui manque ; le sélecteur de langue des réglages, les
   locales Material et le format des dates se déduisent de l'enum, rien d'autre à brancher.

## Vérifier

`python3 tools/i18n-audit` rend 0 quand chaque texte utilisé est traduit dans chaque langue, que les
paramètres `{n}` concordent et qu'aucun texte français n'est écrit en dur. Le test
`test/i18n_coverage_test.dart` lance cet audit dans `flutter test`.

## Limites connues

- Les pluriels suivent le modèle « un / plusieurs » (`tn`) ; une langue à plusieurs formes de pluriel
  demandera d'étendre `tn`.
- Le contenu des messages fictifs du mode démonstration (`lib/data/seed.dart`, `documents.dart`) reste en
  français : c'est du contenu, pas de l'interface.
