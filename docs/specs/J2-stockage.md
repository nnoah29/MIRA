# J2 — Ports, profil et stockage

Références : D-10, D-13, D-16, D-18, D-27, 7.7, 8.1, 8.4, 9.8, 15.1, annexe H ; invariants 7–16, 29. Plan d'ensemble et **schéma SQL imposé** : `docs/specs/CORE-ARCHITECTURE.md` §2, §3, §4.

Le socle `storage/` (fichiers `mod.rs`, `database.rs`, `tx.rs`, `migrations/`) est écrit par l'agent principal avant ce jalon : `Database::open(path)`, `Database::open_in_memory()`, `Database::write(|tx: &Tx| …)`, `Database::read(|tx: &Tx| …)`, conversion des erreurs `rusqlite` en `MiraError` (`local_storage.*`). Les dépôts sont des blocs `impl Tx<'_> { … }` répartis dans des fichiers par entité (`storage/repositories/<entité>/<opération>.rs`), ≤ 6 fonctions par fichier. **Aucun SQL hors de `storage/`. Aucun type `rusqlite` hors de `storage/`.**

Ce jalon est découpé en deux tâches parallèles, sur des fichiers disjoints :

## J2a — Ports, profil, configuration, intentions, événements (agent A)

Fichiers : `src/ports/**`, `src/profile/**`, `src/events/store/**` (ou `src/storage/repositories/events/**`), `src/storage/repositories/{accounts,identities,drafts,actions,events,allowances}/**`.

1. `ports/` : `Clock`, `SystemClock`, `ManualClock` ; `IdGenerator`, `UuidV7Ids` (crate `uuid`, feature v7), `SequentialIds` ; `SecretValue` (Debug/Display → `***`), `SecretStore`, `KeyringSecretStore` (crate `keyring` 4.x : `keyring::Entry::new(service = "mira", user = secret_ref.storage_key())` — consulter `cargo doc` local ou les sources dans `~/.cargo/registry` pour l'API exacte ; erreurs → `secrets.keyring_unavailable` ou `secrets.keyring_locked` ; « pas d'entrée » → `Ok(None)`), `MemorySecretStore` (+ `MemorySecretStore::unavailable()`).
2. `profile/` : `ProfilePaths::resolve(profile: &ProfileId, env: &ProfileEnvironment)` (où `ProfileEnvironment { mira_home: Option<PathBuf>, xdg_data_home: Option<PathBuf>, home: Option<PathBuf> }` est injecté, pour tester sans toucher aux vraies variables), `ProfilePaths::ensure_created()` (droits 0o700), `ProfileLock::acquire(&ProfilePaths)` (`File::try_lock`, `incompatible_state.profile_locked`).
3. Dépôts de configuration : comptes (insérer, lire, lister, mettre à jour, changer l'état, marquer « en suppression », supprimer avec cascade), identités (insérer, lister par compte, mettre à jour, définir la valeur par défaut — une seule par compte —, lire), autorisations de contenu distant (ajouter, tester, lister).
4. Dépôts d'intentions : brouillons (insérer, mettre à jour, lire, lister par compte, supprimer ; pièces jointes de brouillon : ajouter, retirer, lister, lire les données), actions (`enqueue` **idempotent** : même `(compte, clé)` → renvoie l'action existante sans en créer une seconde ; `next_ready(account, now)` = la plus ancienne en `pending` dont `not_before <= now`, par `seq` ; `set_state`, `record_failure` (attempts+1, last_error, not_before), `get`, `list(account, states)`, `pending_count`).
5. Événements : `append_event(at, kind) -> Event` (numéro croissant via `seq`), `events_after(after: Option<EventSeq>, limit) -> Vec<Event>`, `prune_events(keep: u64)`.
6. Tests : `invariant_11_account_has_identity` (créer un compte crée son identité par défaut ? → non : c'est le rôle des comptes en J8 ; ici tester que `set_default_identity` n'en laisse qu'une), `invariant_15_no_secret_in_database` (stocker un secret dans `MemorySecretStore`, créer compte et actions, vérifier qu'aucune table ne contient la valeur), `invariant_17_action_persisted_before_attempt` (une action mise en file est relue après fermeture et réouverture de la base), `invariant_18_enqueue_is_idempotent`, `invariant_19_actions_replayed_in_order` (`next_ready` respecte `seq`), événements numérotés et relus après un numéro, verrou de profil (second `acquire` refusé, libéré au `Drop`), `ProfilePaths` (MIRA_HOME prioritaire, XDG sinon), `SecretValue` masqué dans `format!("{:?}")`, `KeyringSecretStore` : **aucun test automatique ne touche le vrai trousseau** (un seul test `#[ignore = "manuel : utilise le vrai trousseau"]`).

## J2b — Miroir du serveur et recherche (agent B)

Fichiers : `src/storage/repositories/{mailboxes,messages,appearances,server_ids,raw_sources,parsed_cache,attachments,threads,search,mirror,maintenance}/**`.

1. Boîtes : `upsert_mailbox` (par `(compte, nom)` ; conserve l'id existant), `get_mailbox`, `list_mailboxes(account)`, `find_mailbox_by_role(account, role)`, `find_mailbox_by_name`, `set_mailbox_marker`, `delete_mailbox`, `refresh_mailbox_counters(mailbox)` (total et non lus calculés depuis les apparitions non supprimées et `messages.seen`).
2. Messages : `insert_message(&MessageSummary, sort_date)`, `get_message(id) -> Option<MessageSummary>` (avec `mailboxes` rempli depuis les apparitions), `update_message_flags(id, Flags)`, `set_content_state`, `delete_message`, `set_thread(id, Option<ThreadId>)`, `list_messages_in_mailbox(mailbox, PageRequest) -> Page<MessageSummary>` (tri `sort_date DESC, id DESC`, curseur opaque, sans `OFFSET`).
3. Apparitions (D-12, D-14) : `add_appearance`, `remove_appearance(message, mailbox)`, `appearances_of_message`, `appearance_by_uid(mailbox, uid)`, `uids_in_mailbox(mailbox) -> Vec<(u32, MessageId)>`, `set_appearance_deleted`, `mark_mailbox_for_revalidation(mailbox)`, `revalidate_appearance(message, mailbox, new_uid)`, `purge_unrevalidated(mailbox) -> Vec<MessageId>` (renvoie les messages qui n'ont plus aucune apparition, à supprimer du miroir), `delete_orphan_messages(account)`.
4. Correspondance des identifiants (D-13) : `map_server_id(account, kind, value, message)`, `find_by_server_id(account, kind, value) -> Option<MessageId>`, `forget_uid_ids_for_mailbox(mailbox)`, `find_by_fingerprint(account, message_id_header, date, size) -> Vec<MessageId>` (recoupement de dernier recours ; renvoie **tous** les candidats, l'appelant décide — P7).
5. Source brute et cache (D-16) : `store_raw_source(message, &[u8])` (zstd niveau 3), `load_raw_source(message) -> Option<Vec<u8>>`, `store_parsed(message, text, html)`, `load_parsed`, `clear_parsed_cache(account)`.
6. Pièces jointes : `insert_attachment`, `list_attachments(message)`, `get_attachment`, `set_attachment_cache_path(id, Option<path>)`.
7. Fils (table dérivée) : `upsert_thread(account, root_key, subject) -> ThreadId`, `get_thread`, `list_threads_in_mailbox(mailbox, PageRequest)`, `messages_of_thread(thread)`, `clear_threads(account)`.
8. Recherche FTS5 : `index_message(message, subject, addresses, body)`, `unindex_message`, `search_messages(account: Option, query: &str, PageRequest) -> Page<MessageSummary>` (requête utilisateur échappée : chaque mot entre guillemets doubles, pour qu'aucune syntaxe FTS ne soit injectée), `rebuild_search_index()`.
9. Miroir et maintenance : `discard_account_mirror(account)` (invariant 16), `storage_stats() -> StorageStats { messages, raw_bytes, attachments_cached, … }`, `integrity_check() -> bool` (`PRAGMA integrity_check`).
10. Tests : `invariant_7_internal_id_survives_uid_change`, `invariant_8_message_without_appearance_is_purged`, `invariant_9_appearance_mailbox_same_account` (refus si la boîte n'est pas du même compte : vérifier dans `add_appearance`, erreur `invalid_input.parameter`), `invariant_12_flags_live_on_message`, `invariant_14_raw_source_roundtrip_compressed`, `invariant_16_discard_mirror_keeps_config_and_intentions`, `invariant_29_list_is_cursor_paginated` (3 pages de 2 sur 5 messages, sans doublon ni trou), recherche FTS avec accents (`été` trouve `ete`) et injection (`"a" OR 1` ne casse rien), compteurs de boîte.
